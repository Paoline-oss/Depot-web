# Td et TP de Web - Licence Informatique 
Ce dépot Github regroupe l'ensemble de mes td et tp réalisés pendant les cours de développement web. 
## Structure de dépot  :
Le dépot est organisé par séance : 
  - "TD1_HTML_CSS" : Base du HTML et CSS, avec la premiére maquette de site web 
  - "TD2 JS" : Découverte de JS, avec un convertisseur et un formulaire
  - "TD3 DOM-JS" : Manipulation du DOM avec exclusivement l'utilisation de JS
  - "TD4 Bootstrap" : Découverte de Bootstrap
  - "TD5 Vue.js" : Découverte de Vue.js, et son utilisation avec un fichie .json
  - "TD6 Typescript et création d'API personnalisée"
  - "TD6 React" : Découverte de React, et mise en place d'un projet avec Vite
